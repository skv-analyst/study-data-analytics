- [x] **1. Intro to AI Agents LLM**
  - **Резюме.** ИИ-агент — это сложная система, в которой большая языковая модель (LLM) выступает в роли "мозга" или своеобразной операционной системы, работающей по принципу предсказания следующего токена. Поскольку сами по себе LLM имеют ряд ограничений (отсутствие актуальных фактов после обучения, проблемы с точными вычислениями и долгим планированием), архитектура агента компенсирует их за счет интеграции с инструментами, памятью, навыками рассуждения и защитными барьерами (guardrails). Такая эволюция от обычных текстовых промптов к многошаговым агентным пайплайнам позволяет искусственному интеллекту не просто генерировать текст, а автономно планировать и совершать реальные действия во внешних системах.
  - **Артефакты.** [Лекция](https://www.youtube.com/live/C1OCgbONSAw), [код](./01-intro-to-ai-agents-llm.ipynb)
- [x] **2. Tools. MCP**
  - **Резюме.** Инструменты (Tools) расширяют возможности языковых моделей, позволяя им взаимодействовать с внешними системами, получать актуальные данные и совершать реальные действия, при условии их надежного проектирования с учетом безопасных повторов (retries) и обработки ошибок. Для стандартизации, масштабирования и удобного повторного использования множества инструментов применяется Model Context Protocol (MCP) — открытый стандарт клиент-серверной архитектуры, который работает как "универсальный порт" (USB-C) между ИИ-моделями и внешними API. При этом внедрять архитектуру MCP рекомендуется только тогда, когда возрастающая сложность агента действительно этого требует, чтобы избежать излишнего переусложнения системы (over-engineering) на старте.
  - **Артефакты.** [Лекция](https://www.youtube.com/live/VctYHtCap3o), [код](./02-intro-to-tools-mcp-llm.ipynb)
- [x] **3. Memory and Guardrails in LLM-Powered Agents. Лекция.**
  - **Резюме.** Память (краткосрочная, долгосрочная и технологии вроде RAG) превращает базовую языковую модель в полноценного агента, позволяя ему накапливать знания и непрерывно поддерживать контекст диалога. Однако, поскольку такие агенты способны совершать реальные действия, им критически необходима встроенная система защиты (Guardrails), которая является обязательной частью архитектуры. Эта система использует многоуровневые фильтры контента и строгие ограничители действий, чтобы предотвратить катастрофические последствия от инъекций промптов, джейлбрейков и галлюцинаций.
  - **Артефакты.** [Лекция](https://www.youtube.com/live/iJGh5cBSReo)
