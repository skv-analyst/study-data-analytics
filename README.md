# Прикладная аналитика данных

Книга для аналитиков данных от канала «Помидорки резать»: библиотеки, методы и подходы — краткая теория,
практика с кодом и выводы. Собирается
[Jupyter Book](https://jupyterbook.org/) из папок тем.

- Тема = папка = часть книги. Оглавление — [`_toc.yml`](_toc.yml), настройки — [`_config.yml`](_config.yml).
- У каждой темы своё окружение (`<тема>/pyproject.toml`); для сборки книги — лёгкое окружение в корне.
- Главы книги — markdown в `<тема>/chapters/`, рабочие ноутбуки с кодом — в `<тема>/notebooks/` (в книгу не входят).
- Шпаргалка по оформлению главы (вопрос в зал, ответ под катом, картинки) — [`_templates/chapter.md`](_templates/chapter.md).

## Собрать и посмотреть книгу локально

```bash
uv sync
uv run jupyter-book build .
```

Готовый сайт — в `_build/html/index.html`, его можно открыть прямо в браузере.
