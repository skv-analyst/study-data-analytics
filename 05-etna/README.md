# Etna - time series forecasting

Локальное окружение для работы с фреймворком временных рядов ETNA (версия 3.0.0) на компьютерах Mac с процессорами Apple Silicon (M1/M2/M3/M4).

---

## 🛠️ Системные требования

Поскольку пакеты numba и llvmlite требуют компиляции из исходников под архитектуру arm64, в системе должен быть установлен компилятор LLVM через Homebrew:

    brew install llvm

---

## 🚀 Быстрый старт (Установка с нуля)

Если нужно развернуть проект заново или перенести на чистую машину, выполни эти 3 шага в терминале проекта:

### 1. Инициализация проекта и создание окружения
Используем строго Python 3.11, так как под него стабильно собираются все C++ зависимости:

    uv init --python 3.11
    uv venv

### 2. Компиляция и установка ETNA
Устанавливаем библиотеку напрямую из официального Git-репозитория разработчиков. Обязательно прокидываем путь к установленному через brew компилятору LLVM_CONFIG:

    LLVM_CONFIG="$(brew --prefix llvm)/bin/llvm-config" uv pip install "etna[all]@git+https://github.com/etna-team/etna.git@3.0.0"

### 3. Фиксация зависимостей в проекте
Чтобы зафиксировать установленные пакеты и сгенерировать файл блокировки uv.lock, выполни:

    uv sync

---

    # Скачивание и проверка работы датасета
