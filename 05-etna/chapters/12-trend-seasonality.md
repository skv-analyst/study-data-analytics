Ряд почти всегда можно разложить на три части: **тренд** (куда ряд движется в целом), **сезонность** (узор, который
повторяется с периодом — неделя, год) и **остаток** (шум). Многие модели хорошо работают только с одной из частей:
сезонное среднее не видит роста, деревья не умеют продолжать тренд за пределы истории. Задача главы — понять, как
ETNA находит тренд и сезонность и как отделить их от ряда, чтобы модели было проще.

## 1. Теория

### 1.1 Идея

**Тренд мешает моделям, которые его не видят.** Сезонное скользящее среднее прогнозирует среднее за прошлые недели —
если ряд растёт, прогноз всегда будет ниже факта. Деревья (CatBoost) не прогнозируют значений больше, чем видели в
обучении. Выход — **детрендинг**: найти тренд, вычесть его, обучить модель на остатке, а в прогнозе прибавить тренд
обратно.

**Сезонность сначала надо увидеть.** Какой период у ряда — неделя, месяц, год — подсказывают графики:

| график | что показывает | признак сезонности |
|---|---|---|
| `acf_plot` | насколько ряд похож на себя же, сдвинутый на 1, 2, … дней (автокорреляция) | пики на лагах, кратных периоду: 7, 14, 21 |
| `plot_periodogram` | «силу» каждой частоты в ряде | высокий пик на частоте периода |
| `seasonal_plot` | каждый цикл (неделя, год) — отдельной линией | линии повторяют одну форму |
| `stl_plot` | ряд, разложенный на тренд, сезонность и остаток | в остатке не осталось узора |

**Дальше два пути:**

1. **убрать** — трансформ вычитает тренд или сезонность, модель учится на остатке, а в прогнозе трансформ
   возвращает вычтенное (трансформы обратимые);
2. **описать признаками** — сезонность не трогают, а дают модели признаки, по которым она её выучит
   (`FourierTransform`, признаки даты из главы про CatBoost). Это путь для ML-моделей.

### 1.2 Параметры и реализация

#### Трансформы тренда

Вычитают из ряда найденный тренд, а в прогнозе продолжают его на будущее (исходники
`etna/transforms/decomposition/`):

| трансформ | как ищет тренд | главные параметры |
|---|---|---|
| `LinearTrendTransform` | обычная регрессия: прямая (или многочлен), ближе всего к точкам в среднем | `poly_degree` — степень многочлена |
| `TheilSenTrendTransform` | регрессия Тейла–Сена: наклон — медиана наклонов между парами точек, поэтому выбросы почти не влияют | `poly_degree` — степень многочлена |
| `ChangePointsTrendTransform` | ищет точки излома тренда и на каждом отрезке между ними строит свою прямую; в прогноз уходит прямая последнего отрезка | `change_points_model` — как искать изломы и сколько; `per_interval_model` — модель на отрезке |
| `DifferencingTransform` | не ищет тренд, а заменяет значения разностями: сегодня минус вчера (или минус `period` дней назад) | `period`, `order` — сколько раз взять разность |

```python
class LinearTrendTransform(ReversiblePerSegmentWrapper):
    def __init__(self, in_column: str, poly_degree: int = 1, **regression_params):

class TheilSenTrendTransform(ReversiblePerSegmentWrapper):
    def __init__(self, in_column: str, poly_degree: int = 1, **regression_params):

class ChangePointsTrendTransform(ReversibleChangePointsTransform):
    def __init__(
        self,
        in_column: str,
        change_points_model: Optional[BaseChangePointsModelAdapter] = None,
        per_interval_model: Optional[PerIntervalModel] = None,
    ):
```

По умолчанию `ChangePointsTrendTransform` ищет **5 изломов** алгоритмом `Binseg` из библиотеки `ruptures`, а на
отрезках строит `LinearRegression`. Если число изломов известно, его лучше задать:

```python
from ruptures import Binseg
from etna.transforms.decomposition.change_points_based.change_points_models import RupturesChangePointsModel

ChangePointsTrendTransform(
    in_column="target",
    change_points_model=RupturesChangePointsModel(change_points_model=Binseg(model="linear"), n_bkps=1),
)
```

#### Трансформы сезонности

`STLTransform` и `DeseasonalityTransform` вычитают сезонность и возвращают её в прогноз, `FourierTransform` только
добавляет признаки:

| трансформ | что делает | главные параметры |
|---|---|---|
| `STLTransform` | раскладывает ряд методом STL и вычитает тренд и сезонность сразу; в прогнозе сезонность повторяется, а тренд продолжает модель | `period`; `model` — чем продолжать тренд (`"arima"` или `"holt"`); `robust` — устойчивость к выбросам |
| `DeseasonalityTransform` | вычитает средний узор периода (или делит на него), найденный классическим разложением на скользящих средних | `period`; `model` — `"additive"` (вычесть) или `"multiplicative"` (разделить) |
| `FourierTransform` | ничего не вычитает, а добавляет колонки-признаки: синусы и косинусы с периодом `period` | `period`; `order` — сколько гармоник (колонок будет `2 · order`); `out_column` |

```python
class STLTransform(ReversiblePerSegmentWrapper):
    def __init__(
        self,
        in_column: str,
        period: int,
        model: Union[str, Type[TimeSeriesModel]] = "arima",
        robust: bool = False,
        model_kwargs: Optional[Dict[str, Any]] = None,
        stl_kwargs: Optional[Dict[str, Any]] = None,
    ):

class DeseasonalityTransform(ReversiblePerSegmentWrapper):
    def __init__(self, in_column: str, period: int, model: Literal["additive", "multiplicative"] = "additive"):

class FourierTransform(IrreversibleTransform):
    def __init__(
        self,
        period: float,
        order: Optional[int] = None,
        mods: Optional[Sequence[int]] = None,
        out_column: Optional[str] = None,
        in_column: Optional[str] = None,
    ):
```

#### Как применять

Сначала посмотреть на тренд глазами — `plot_trend` рисует найденные трансформами тренды поверх ряда:

```python
plot_trend(ts, trend_transform=[LinearTrendTransform(in_column="target"), TheilSenTrendTransform(in_column="target")])
```

Сезонность — графиками из таблицы в 1.1. Потом поставить выбранный трансформ в конвейер — он сам вычтет тренд или
сезонность перед обучением и вернёт их в прогноз:

```python
pipeline = Pipeline(
    model=SeasonalMovingAverageModel(window=4, seasonality=7),
    transforms=[STLTransform(in_column="target", period=7)],
    horizon=14,
)
```

### 1.3 Особенности

- **В прогноз уходит конец тренда.** Ошибка тренда в середине истории почти не важна, важен наклон в последних
  точках: с ним тренд продолжится на весь горизонт.
- **Неправильный тренд хуже, чем никакого.** Прямая через ряд с изломом показывает рост, когда ряд уже падает, — и
  прогноз уезжает в другую сторону.
- **`LinearTrendTransform` чувствителен к выбросам,** `TheilSenTrendTransform` — нет. Выбросы лучше убрать до
  поиска тренда (глава [«Обработка выбросов»](11-outliers.md)) или взять Тейла–Сена.
- **`ChangePointsTrendTransform` по умолчанию ищет много изломов:** последний отрезок получается коротким, и его
  наклон неустойчив. Если изломов мало, задай их число.
- **Заглядывание в будущее.** `STLTransform`, `DeseasonalityTransform` и `ChangePointsTrendTransform` обучаются на всей
  переданной истории: при `fit` на всём ряде трансформ видит тестовый период. В конвейере и backtest это не
  проблема — там трансформ обучается только на train.
- **`FourierTransform` необратимый:** он только добавляет признаки, а ряд не меняет — возвращать в прогнозе нечего.
  Без ML-модели, которая умеет пользоваться признаками, он бесполезен.

## 3. Итоги

- **Тренд ищи под форму ряда:** прямой — `TheilSenTrendTransform` (устойчив к выбросам), с изломом —
  `ChangePointsTrendTransform` с заданным числом изломов. Смотри на наклон в конце: именно он уйдёт в прогноз.
- **Неправильный тренд хуже, чем никакого** — проверяй его на графике `plot_trend`, прежде чем ставить в конвейер.
- **Сезонность сначала находят графиками** (`acf_plot`, `seasonal_plot`, `stl_plot`), потом либо вычитают
  (`STLTransform`, `DeseasonalityTransform`), либо отдают ML-модели признаками (`FourierTransform`).
